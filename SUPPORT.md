# Support

This is open source maintained by one person alongside other work.

**No SLA.** Issues are triaged roughly weekly, in a fixed and deliberately small
time budget. A clear bug report with a sample file attached gets handled far
faster than a question that needs a conversation first.

Good issue:

- what you put in (attach the log, trimmed is fine)
- what came out
- what should have come out
- version, and whether you are on Node or in a browser

**Security issues:** do not open a public issue. This library parses untrusted
files, so a crash or a resource-exhaustion case is worth reporting privately.
Use GitHub's private vulnerability reporting on this repository.

**Commercial support** is not offered for this package. The hosted Qorbit
platform is a separate product with its own support; this repository is not the
channel for it.
